# QA gates for Claude Code
1. `npm install`, `npm run typecheck`, `npm test` and lint complete, or report precisely why not.
2. App starts in Expo and all five core screens have real navigation.
3. First-time onboarding persists across relaunch, editable in settings.
4. Beginner plan schedules safe rest days; no fake metrics.
5. Can complete at least one workout end-to-end with saved log and correct progress updates.
6. Exercise instructions include muscles/steps/mistakes/easier/harder; show "content requires review" disclaimer where relevant.
7. Blob always cream-white with two black oval eyes and BLACK shorts. No unrelated competitor-inspired art.
8. VoiceOver/TalkBack labels and sufficient contrast; phone sizes and safe area respected.
9. No backend or subscription accidentally introduced.
10. Provide implementation summary, tests performed, gaps, screenshots and reproducible commands.
